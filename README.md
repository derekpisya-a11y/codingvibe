# Komorebi — маленький мир больших чувств

Уютный адаптивный сайт об оригинальных аниме-героинях. Пастельные цвета, локальные иллюстрации и шрифты, поиск, фильтры по настроению, истории персонажей и избранное с сохранением в браузере. Серверная часть и ключи API не нужны.

## Открыть без установки

Готовый файл `dist/komorebi.html` можно открыть прямо в браузере двойным щелчком. В нём уже находятся изображения, шрифты и скрипты; интернет не требуется. Файл появляется после сборки. Избранное сохраняется при разрешённом локальном хранилище браузера.

## Разработка

Требуется Node.js 22.12+ или 24 LTS и npm.

```sh
cd /workspace/codingvibe
npm ci --cache /tmp/codingvibe-npm-cache --no-audit --no-fund
npm run dev -- --port 5173 --strictPort
```

## Сборка и публикация

```sh
npm run build
npm run preview -- --port 4173 --strictPort
```

Результат находится в `dist/`. Папку можно разместить на любом статическом хостинге, в том числе в подпапке домена. `dist/komorebi.html` — самостоятельная версия в одном файле. Скрипт сборки собирает её из тех же файлов, что и обычный сайт.

Работающий процесс разработки не означает публикацию сайта в интернете. Публичный хостинг для этого проекта пока не настроен.

## Возможности

- Четыре оригинальные героини с персональными историями и иллюстрациями.
- Фильтры, поиск по именам и увлечениям, подбор по настроению.
- Избранное в `localStorage`, отдельный просмотр коллекции.
- Случайная история и добрые пожелания без повторения подряд.
- Диалоги с закрытием по Escape, возвратом фокуса и управлением с клавиатуры.
- Мобильное меню и поддержка `prefers-reduced-motion`.

Изображения и шрифты хранятся локально. Нет внешних запросов, аналитики, регистрации и серверного хранения пользовательских данных.
